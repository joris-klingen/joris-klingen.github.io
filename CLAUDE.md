# joris-klingen.github.io — agent signpost

Personal website of Joris Klingen (economist at CPB Netherlands Bureau for Economic Policy Analysis).
Quarto website, published to GitHub Pages from the `gh-pages` branch. Source on `main`.

## Where content comes from

- **Papers are not edited here.** `data/papers.yml` is generated by the research hub
  (`Dropbox/1_research/.00_research_hub`, private repo `joris-klingen/research-hub`) from its
  `papers/*.yaml`: `python scripts/build_registry.py --website` in the hub copies it in. To change a
  paper's title, status, co-authors, summary or links, edit the hub's YAML and re-export.
- `research.qmd` lists the papers in three Quarto listings (published, work in progress, thesis), filtered on
  `status`, rendered by `_templates/papers.ejs`. Keep HTML in that template unindented (Quarto reads the
  output as Markdown; indented lines become code blocks).
- The other pages (`index.qmd`, `teaching.qmd`, `music.qmd`, `ozone-cycling.qmd`) are written by hand.
  `ozone-cycling.html` is linked from the ozone paper's entry: keep that file name.
- Look: `styles.scss` (on top of the `cosmo` theme). Inter font, accent `#1a5276`.

## Build and publish (by hand)

Quarto ships with RStudio: `"C:/Program Files/RStudio/resources/app/bin/quarto/bin/quarto.exe"`.

```
bash publish.sh               # commit first: renders HEAD in a temp folder, pushes _site to gh-pages
quarto preview                # local preview with reload (may hit the Dropbox lock; retry)
```

Do not use `quarto publish gh-pages` or `quarto render` here: Dropbox locks `.quarto/` mid-render ("being
used by another process"), even with the Dropbox-ignore flag on it. `publish.sh` renders outside Dropbox
instead. Pages serves the `gh-pages` branch.

## Conventions

- Branch `main` is the source; feature work on `claude/...` branches. Ask before pushing to `main` or
  publishing.
- Keep it fast, accessible and minimal; check at phone width.
- `ref_old_website/` holds screenshots of the old Google Sites page (gitignored).
