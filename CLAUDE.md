## Goal

Rebuild and improve Joris Klingen's personal website. This is a GitHub Pages site (`joris-klingen.github.io`).
The original site was hosted on Google Sites at `sites.google.com/view/jorisklingen`.

## Status

- **Phase:** Initial build complete — static site with 3 pages

- **Hosting:** GitHub Pages
- **Framework:** Plain HTML + CSS (no build step)
- **Font:** Inter via Google Fonts
- **Domain:** joris-klingen.github.io

## Development

- **Branch workflow:** Feature branches prefixed with `claude/`
- **Deployment:** Pushes to `main` deploy automatically via GitHub Pages

## Conventions

- Keep the site fast, accessible, and minimal
- No build tools — plain static HTML/CSS for simplicity
- Mobile-first responsive design
- Semantic HTML with clean, maintainable CSS
- Commit messages should be clear and descriptive
